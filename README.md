# Student Management and CGPA Dashboard
A Python-based Student Managenent System built using Streamlit and SQLite.

## Features :
- Add Students
- View Students
- Delete Students
- Add Subject Marks
- Calculate Grades
- Calculate SGPA
- Student Performance Dashboard
- SGPA Visualization
- SQLite Database

## Technologies Used :
- Python
- Streamlit
- SQLite
- Pandas
- Git
- Github
