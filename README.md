# Student Management and CGPA Dashboard
A Python-based Student Managenent System built using Streamlit and SQLite.

## Features :
- Add Students
- View Students
- Delete Students
- Add Subject Marks
- Calculate Grades
- Calculate SGPA
- Student Performance Dashboard
- SGPA Visualization
- SQLite Database

## Technologies Used :
- Python
- Streamlit
- SQLite
- Pandas
- Git
- Github

## Project Purpose :
The **Student Management & CGPA Dashboard** is designed to simplify student record management, automate CGPA calculation, and provide an interactive dashboard to track and analyze academic performance efficiently.
